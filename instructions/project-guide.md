На Spring необходимо сделать серверную часть сайта по изучению языков программирования - Python, Java, C, C++, C#, PHP
Необходимо добавить возмонжость ввода и получения результата исполнения кода пользователем через компилятор. Следует использовать Judge0.

## В проекте должно быть разделение на следующие микросервисы:
### 1. User Service.
- Отвечает за регистрацию профилей, изменение аватарки, настройки аккаунта, информацию об учениках и преподавателях. 
### 2. Course Service.
- Создание курсов по языкам программирования, модулей, публикации материалов, 
- управление структурой обучения
### 3. Task Service.
- Хранение заданий и шаблонов кода, поддерживаемых языков, тестов, ограничений времени и памяти
### 4. Submission Service 
- принимает решения студентов, 
- сохраняет исходный код, 
- управляет очередью проверки на уровне бизнес логики
- Хранит итоговые вердикты: Accepted, Wrong answer, Compilation Error
### 5. Execution Service
- Выбирает язык
- Отправляет запросы в Judge0
- Получает stdout, stdin метрики
- Обрабатывает ошибки и технические повторные попытки
### 6. Progress Service
- Отслеживает пройденные уроки, задачи, статистику обучения и прогресс по курсам. 

## Необходимо сделать:
1. Настроить Spring Cloud Config
2. Использовать Eureka для обнаружения и регистрации сервисов
3. Создать API Gateway(Настройте Spring Cloud Gateway для маршрутизации запросов к соответствующим микросервисам.)
4. Добавить поддержку Circuit Breaker
5. Реализовать мониторинг и логирование. Настроить Spring Boot Actuator, а также реализуйте базовое логирование сервисов
6. Создать API документацию для каждого сервиса (Swagger), подписать каждый эндпоинт. 
7. Использовать keycloak для аутентификации, управлением аккаунтами и токенами.
8. Spring Security OAuth2 Resource Server — проверка JWT внутри Gateway и микросервисов.
9. Реализовать контроль версии базы данных при помощи Flyway
10. Использовать Redis для быстрого хранения временных данных
11. При помощи RabbitMQ реализовать асинхронный обмен сообщениями
12. Настроить OpenTElemetry для прослеживания запросов между сервисами, очередью и Judge0.
